# QuickLang

让每一次回忆，都更清晰。

QuickLang 是个人背单词应用框架，提供键盘拼写、卡片回忆与逐字自动默念的桌面预览。
业务核心使用 Rust，界面使用 React，桌面壳使用 Tauri 2。

当前版本：0.1.0 框架。seekdb 持久化尚未接入，预览不保存学习进度。
