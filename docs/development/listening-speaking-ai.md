# 听说练习与 AI 教练

日期：2026-09-14。

## 入口与使用

选择用户后，从侧栏进入“听说练习”。材料包括三组原创短对话、当前词书的例句，以及用户主动生成的 AI 练习。

1. 播放整段或当前句，先保持字幕隐藏；按需显示英文或双语字幕。
2. 听写当前句，提交后查看缺词、多词和正确词。忽略大小写、常见标点，保留缩写及词内连字符差异；这是文本比对，不是语义或口语评分。
3. 短对话提供两道理解题。生成题的结构经过校验，内容与答案仍需要核对。
4. 录下跟读或新场景回答，回放并与原音比较。录音最长 60 秒、最大 8 MB，本次练习最多保留十份；切换练习或离开页面会释放麦克风和录音 URL。
5. 手动填写自己的回答，或主动发送所选录音转写，核对文字后请求 AI 反馈。
6. 回答 AI 的新追问，或修改后重试。首次回答在请求 AI 前先保存，服务失败也会保留原始文字。

录音不会自动上传，也不会自动永久保存。首次录音与重试录音可在当前练习中切换回放，离开前点击下载保留。当前音频为系统合成语音，尚无真人语料或自动发音评分。

## 系统发音

桌面版通过 macOS `/usr/bin/say` 枚举本机音色并生成临时 PCM WAV，由应用播放并在取消时停止，临时文件生成后删除。浏览器预览仍使用 Web Speech API，音色列表可能与桌面版不同。

进入“设置 → 系统设置 → 单词发音”，选择美式或英式英语、系统音色和英文语速，先试听再保存。偏好保存在本设备的 `quicklang:speech-settings`，所有用户的学习模式共用；试听未保存的配置不会改变学习设置。中文释义不使用英文音色或英文语速。

自动选择只考虑应用可访问的本机音色：先匹配口音；美音依次选择 Nathan（Enhanced）、Samantha（Enhanced）、Samantha。三者都不可用时，再按 Premium / Enhanced、系统默认声音等规则选择。显式选择的可用音色仍优先于自动规则。该优先级是名称启发式，不代表实际音质测量。所选声音不可用时退回自动选择；没有本机匹配声音时由系统默认朗读。首次声音列表为空时最多等待一秒，等待和播放均可取消。

Mac 用户可按照 [Apple 官方说明](https://support.apple.com/zh-cn/guide/mac-help/mchlp2290/mac)，在系统设置的辅助功能中下载更多声音，然后回到应用刷新音色列表。列表会在应用重新获得焦点或系统发布声音变更时刷新。部分系统声音可能不会暴露给浏览器或桌面 WebView，下载后仍不可见时可重启应用检查。本功能不自动下载音色，也未接入云端语音服务。

## 服务配置

在“系统设置”配置 API 根地址、对话模型和可选的语音转写模型。根地址应包含服务所需版本路径，例如 `https://your-service.example/v1` 或 `http://127.0.0.1:11434/v1`。

- 对话调用根地址下的 `chat/completions`，使用 `model`、`messages`、`stream: false`、`max_tokens: 900`，读取 `choices[0].message.content`。
- 转写调用 `audio/transcriptions`，发送 multipart 的 `model`、`language: en` 和 `file`，读取 `text`。服务必须支持浏览器实际录制的音频容器。
- 本机模型若无需鉴权，可留空密钥。密钥只保留在应用运行内存，不写入练习记录。
- 桌面由 Rust 发起请求，避免浏览器跨域问题；浏览器预览要求服务允许 CORS。
- 远程地址必须使用 HTTPS；仅回环地址允许 HTTP。禁用 HTTP 重定向，不向页面返回服务端原始错误正文。连接超时 10 秒、请求超时 60 秒，响应上限 256 KB。
- 页面离开后忽略迟到结果。桌面底层请求可能继续至完成或 60 秒超时，不承诺取消已发生的服务计费。

没有配置服务时，听写、理解题、录音回放与文字自评仍然可用。系统语音能否离线播放取决于设备是否已安装相应语音。

## 数据与训练边界

文字记录使用现有按用户隔离的本机存储，键为 `quicklang:user:<id>:conversation:<bookId>`；最多保留最近 200 次。包含题目、原始回答、时间、文字提示使用、听写/理解结果及 AI 反馈。AI 生成练习使用 `generated-lessons:<bookId>`，最多保留十组。尚未接入 seekdb 的跨天复习调度或设备同步。

只有用户点击发送后才请求服务：

- 反馈：当前材料、场景任务、当前回答和最近四轮对话。
- 转写：用户当前选中的录音。
- 新情境：当前词书例句的目标词，或词书前五个词及释义。

AI 反馈只讨论文字表达，明确不能推断发音或口音。每次给少量改进和一个新问题，不以生成的润色文本证明用户能力提升。生成练习标记为未经语言审核，文本按普通文字渲染。

## 验证

- UI 测试覆盖听写差异、首次/提示后尝试、用户隔离、理解题、AI 原始回答保留、服务失败、存储失败、生成格式验证和麦克风权限迟到时的清理。
- Rust 测试用本机 HTTP 模拟服务验证对话、转写 multipart 和状态码错误处理，不调用付费服务。
- 浏览器界面实际验收了听说入口、隐藏答案、听写漏词提示和记录增加。
- 尚未使用真实麦克风及真实模型服务完成端到端验收；不同 WebView 的录音格式、系统权限和下载行为需要设备验证。
